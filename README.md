# 🌐 Meus Sites Favoritos

Projeto desenvolvido como atividade da ETEC com o objetivo de criar um site simples contendo alguns dos meus sites favoritos.

---

## 📖 Sobre o Projeto

Este projeto consiste em uma página web simples feita com HTML e CSS, apresentando uma lista de sites que utilizo no dia a dia para estudos, tecnologia, entretenimento e produtividade.

A proposta da atividade é praticar conceitos básicos de desenvolvimento web.

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3

---

## 🎯 Funcionalidades

- Exibição de sites favoritos
- Links externos clicáveis
- Estrutura simples e organizada
- Layout responsivo básico

---

## 📁 Estrutura do Projeto

```bash
📁 meus-sites-favoritos
├── img
├── index.html
├── style.css
└── README.md
```


## 📚 Objetivo Educacional

Projeto desenvolvido para fins educacionais na ETEC, com foco no aprendizado de:

- HTML
- CSS
- Organização de conteúdo
